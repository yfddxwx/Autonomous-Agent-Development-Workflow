## Reporting a Vulnerability

Security is paramount in autonomous development agents, especially regarding arbitrary command execution and filesystem access controls.

If you discover a security vulnerability (such as a path traversal flaw, sandbox bypass, or credential leak), please **do not open a public issue**. Instead, please report it privately:

- **Maintainer**: yifangdong
- **Email**: `254672829@qq.com`
- **Subject**: `[SECURITY VULNERABILITY] Autonomous Agent Development Workflow`

Please include:
1. Description of the vulnerability and attack vector.
2. Step-by-step reproduction instructions or proof-of-concept.
3. Impact assessment.
4. Suggested remediation if available.

We will acknowledge receipt within 48 hours and work with you to patch the issue before public disclosure.
