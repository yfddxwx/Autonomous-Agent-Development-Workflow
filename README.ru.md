## 🌟 Обзор

**Autonomous Agent Development Workflow** — это сверхлегкий, высокопроизводительный агент разработки программного обеспечения на базе ИИ, скомпилированный в один исполняемый файл и написанный с нуля на Go. Он предоставляет разработчикам и инженерным командам автономного партнера по парному программированию, способного планировать задачи, читать и редактировать исходный код, выполнять команды терминала, автоматически устранять ошибки компиляции и исследовать альтернативные ветви архитектурных решений.

В отличие от тяжелых Python-фреймворков, требующих гигабайты виртуальных окружений и зависимостей Node.js, этот агент компилируется в **один бинарный файл размером ~9 МБ**, куда встроен весь современный веб-интерфейс в стиле Google Material 3 / Gemini с помощью директивы `//go:embed`.

## ✨ Ключевые возможности

1. **Единый бинарный файл без внешних зависимостей (`//go:embed`)**
   - Полный фронтенд (HTML, Tailwind CSS, офлайн-движок Markdown, иконки) встроен непосредственно в исполняемый файл.
   - Запуск на Windows, Linux или macOS без предварительной установки зависимостей.

2. **Автономный цикл ReAct и самовосстановление**
   - Реализует парадигму `Think -> Act -> Observe -> Reflect`.
   - При сбое тестов или компиляции агент перехватывает вывод stdout/stderr, диагностирует первопричину и автономно выполняет рефакторинг до успешного завершения.

3. **7-уровневый контроль глубины рассуждений (Pi-Aligned)**
   - Встроенный в строку ввода контроллер усилий рассуждения: `off`, `minimal`, `low`, `medium`, `high`, `xhigh` и `max`.
   - Динамическая адаптация уровней в зависимости от возможностей модели (например, DeepSeek V4.1 Flash, Xiaomi MiMo, Claude 3.7 Sonnet, серия OpenAI o, Gemini 3).

4. **3-уровневые барьеры безопасности HITL (Antigravity Guardrails)**
   - **Manual**: Строгая проверка человеком каждого изменения файла и каждой команды.
   - **Guarded**: Безопасные операции чтения и диагностики выполняются автоматически; деструктивные операции, перезапись файлов и потенциально опасные команды требуют подтверждения в 1 клик.
   - **Auto**: Полная автономия для изолированных сред и песочниц.

5. **Потоковый терминал реального времени**
   - Длительные системные команды передают вывод построчно через протокол RFC 6455 WebSockets во встроенный терминал.

6. **Атомарный откат с поддержкой Git**
   - Мониторинг состояния репозитория в реальном времени с возможностью отката изменений и очистки рабочей копии в один клик.

7. **Дерево сессий и путешествие во времени (Time-Travel)**
   - Автоматические снимки состояния после каждого шага задачи для легкого переключения между гипотезами без потери истории.

8. **Телеметрия токенов и калькулятор затрат**
   - Отслеживание токенов запроса и ответа в реальном времени с оценкой стоимости.

## 🧠 Селектор глубины рассуждений, согласованный с Pi

В строку ввода встроен переключатель усилий рассуждения, откалиброванный по официальным спецификациям экосистемы Pi Agent:

| Уровень | Отображение в UI | Лимит токенов | Типичный сценарий использования |
| :--- | :--- | :--- | :--- |
| `off` | **Отключено (Off)** | 0 токенов | Прямые ответы, форматирование, диалоговые вопросы |
| `minimal` | **Минимальный (Minimal)** | ~1k токенов | Быстрое резюме, поиск по отдельным строкам |
| `low` | **Низкий (Low)** | ~2k токенов | Небольшие правки, генерация простых скриптов |
| `medium` | **Средний (Medium)** | ~8k токенов | Стандартная разработка функций и отладка |
| `high` | **Высокий (High)** | ~16k токенов | Сложные алгоритмы, написание комплексных тестов |
| `xhigh` | **Сверхвысокий (Extra-High)**| ~32k токенов | Архитектурный синтез, межмодульный рефакторинг |
| `max` | **Максимальный (Max)** | Макс. лимит | Исчерпывающий пошаговый анализ и устранение критических багов |

*Интерфейс динамически отображает только те уровни, которые поддерживаются выбранной моделью.*

## 🛡️ Безопасность с участием человека (HITL)

- **Строгое ограничение путей**: Полная защита от атак выхода из каталога (`../`), все операции замкнуты в пределах рабочей директории.
- **Перехват опасных команд**: Шаблоны деструктивных операций (`rm -rf /`, форматирование дисков, доступ к учетным данным) блокируются или требуют явного подтверждения.
- **Визуальный просмотр различий (Diff)**: Хирургическая замена блоков кода отображается контрастным красным/зеленым цветом перед записью на диск.

## 🚀 Быстрый старт

### Требования
- [Go 1.22+](https://golang.org/dl/) (требуется только при сборке из исходного кода)
- Git (опционально, для функций контроля версий)

### 1. Запуск из исходного кода
```bash
# Клонирование репозитория
git clone https://github.com/yfddxwx/Autonomous-Agent-Development-Workflow.git
cd Autonomous-Agent-Development-Workflow

# Запуск сервера DevAgent (порт по умолчанию: 8080)
go run cmd/agent/main.go -port 8080 -dir .
```

Откройте браузер по адресу:
```
http://127.0.0.1:8080
```

### 2. Сборка единого бинарного файла
Создание оптимизированного исполняемого файла:
```bash
# Для Linux / macOS
go build -ldflags "-s -w" -o agent ./cmd/agent

# Для Windows
go build -ldflags "-s -w" -o agent.exe ./cmd/agent
```

## ⚙️ Руководство по настройке

Скопируйте `config.example.json` в `config.json` (или настройте параметры через графический интерфейс):

```bash
cp config.example.json config.json
```

Пример профиля конфигурации:
```json
{
  "active_profile_id": "deepseek-flash",
  "profiles": [
    {
      "id": "deepseek-flash",
      "name": "DeepSeek V4.1 Flash",
      "provider": "deepseek",
      "base_url": "https://api.deepseek.com",
      "api_key": "YOUR_API_KEY_HERE",
      "model": "deepseek-flash",
      "max_steps": 15
    }
  ],
  "workspace_dir": ".",
  "approval_mode": "guarded"
}
```

*Переменные окружения (`DEEPSEEK_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY` и др.) считываются автоматически при запуске.*

- **Стиль Google Gemini**: Шрифты Google Sans, JetBrains Mono для кода и темные эргономичные поверхности (`#131314`).

## 🧪 Тестирование и контроль качества

Каждый pull request и релиз проверяются по четырем критериям надежности:

```bash
# Запуск полного набора модульных и интеграционных тестов
go test -v ./...
```

Проверочные тестовые наборы:
- `pkg/security`: Ограничение путей, перехват опасных команд и шлюз авторизации.
- `pkg/tools`: Точечная замена блоков, листинг директорий и потоковый вывод команд.
- `pkg/server`: Динамическое переключение профилей, валидация уровней рассуждений и маршрутизация API.
- `pkg/git`: Безопасность отката и мониторинг состояния репозитория.
- `tests`: Сквозное автономное тестирование цикла ReAct.
